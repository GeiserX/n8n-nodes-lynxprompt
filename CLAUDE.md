# CLAUDE.md — n8n-nodes-lynxprompt

## Overview
n8n community node for LynxPrompt, enabling management of AI configuration blueprints (AGENTS.md, CLAUDE.md, .cursorrules) and hierarchies via the LynxPrompt API within n8n workflows.

## Tech Stack
- TypeScript
- n8n community node SDK
- Vitest (test framework)
- Node.js (build via `package.json` scripts)

## Development
```bash
npm install
npm run build        # Compile TypeScript
npm run lint         # Lint source
npm test             # Run vitest suite

# Icon generation
node build-icons.cjs
```

## Architecture
- `nodes/` — Node implementations (LynxPrompt CRUD + LynxPrompt Trigger)
- `credentials/` — LynxPrompt API credential definition (URL + `lp_` token)
- `tests/` — Vitest test suite
- `docs/` — Documentation and images

## Key Rules
- Never hardcode API tokens; use n8n credential system with `lp_` prefixed tokens
- Follow n8n community node conventions for resource/operation patterns
- Supports both polling triggers (new blueprint, blueprint updated) and regular CRUD
- Package published to npm as `n8n-nodes-lynxprompt`
